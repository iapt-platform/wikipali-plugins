安装插件

在 Claude Code 里两条命令，装好后重启会话

2

佛教问答

3

佛教百科生成

术语表 + 出处分布 + 原典阅读，整理成一篇带引用的百科条目

4

经文翻译与回写 WikiPali

以 AI 模型身份写入你的译文 channel，并生成阅读链接

安装：/plugin marketplace add iapt-platform/wikipali-plugins → /plugin install wikipali@wikipali
