# 读缅文 nissaya

nissaya（နိဿယ）是缅甸传统的巴利逐词讲解：先引巴利词，再用缅文给出意思和语法。
它**不是严格的词对词翻译**——会重排语序、补出原文省略的成分、对难词给释义而非对译，
而缅文语尾本身就是对巴利词格位、时态、修饰关系的分析。评审译文、研究句法时用它作
**语法佐证**，前提是读懂它。

本文的例子都取自中部《优波离经》（MN 56，坐标 165:124 起）。

## 取数据

nissaya 是一个独立 channel（类型 `nissaya`，语言 `my`），uid 各站点不同，先查：

```bash
wikipali versions 165:124                       # [nissaya] 下那一行就是
wikipali get 165:124 --channel <nissaya-uid> --json
```

`content` 是 markdown 源码，一行一条 gloss：`巴利词= 缅文。`（`=` 左边巴利、右边缅文，
见 `api-read.md`）。注意：

- **巴利词是缅文字母书写的**（`ဧကံ= သော။` 即 `ekaṃ = sā`），不是罗马字。对照原文
  时要先转写；网页阅读页显示的罗马字是转写后的结果。
- **gloss 按句子存，但不严格对齐句子边界**：一句的讲解可能放在**前一句或后一句**的
  条目里（165:190 `2-26` 的条目末尾讲的是下一句 `yaṃ maṃ bhagavā evamāha`）。判断一句时
  把**前后相邻句**的 nissaya 一起读。
- **大量句子没有条目，这不等于没讲**。抽样《优波离经》前 200 句，约三分之一为空，
  几乎都是重复段落：nissaya 用 `ပ` 跳过（见「省略记号」），或在方括号里注明「仿照
  第 56 段讲」，只列出不同的词。遇到空条目，**往前找平行段落**的讲解。
- 段首的缅文数字（`၆၈။`）是巴利段号（这里是第 68 段），不是 gloss。
- 有的 channel 叫「AI-汉译-Nissaya」之类，是**把 nissaya 机器译成汉语**的产物，不是
  nissaya 本身，按机器译文对待（`conventions.md`「译文来源的判定」）。

## 语序：按缅文重排

nissaya 按缅文语序（修饰语在前、动词在末）重新排列巴利词，**不能按位置对原文**。

> 原文 `nigaṇṭho nāṭaputto … nāḷandāyaṃ paṭivasati mahatiyā nigaṇṭhaparisāya saddhiṃ`
> nissaya `nāṭaputto ကခြေသည်၏သားဖြစ်သော nigaṇṭho နိဂဏ္ဌသည် mahatiyā များပြားသော
> nigaṇṭhaparisāya နိဂဏ္ဌပရိသတ်နှင့် saddhiṃ အတူတကွ nāḷandāyaṃ နာဠန္ဒာမြို့၌ paṭivasati နေ၏`

`nāṭaputto` 被挪到 `nigaṇṭho` 前面并带定语语尾 `သော`——这就是在说 nāṭaputto 修饰
nigaṇṭho。**重排本身就是修饰关系的分析。**

## 语尾 = 语法分析

gloss 有两种：

- **只有语尾**：`ဧကံ= သော`、`နိဂဏ္ဌော= သည်`。意思不必译（专名、常见词、前文已译），
  只交代语法。
- **释义 + 语尾**：`နာဠန္ဒာယံ= နာဠန္ဒာမြို့၌`（那烂陀城 + 处格）。

评审「主谓宾判断」「修饰错误」「指代错误」主要看语尾。下表是常见语尾，⚠ 标的是
**待核对**的项——用之前若有疑问，以巴利语法和注释书为准。

### 名词、形容词

| 语尾 | 对应巴利 | 例 |
|---|---|---|
| `သည်` | 主格（主语） | `bhagavā သည်` |
| `ကို` | 宾格（宾语）；⚠ 有时也对应与格 | `nigaṇṭhaṃ ကို` |
| `၏`（接名词后） | 属格 | `nigaṇṭhassa ၏` |
| `၌` | 处格（地点、时间） | `nāḷandāyaṃ ၌`、`samaye ၌` |
| `နှင့်` | 具格（偕同，常配 saddhiṃ） | `nigaṇṭhaparisāya နှင့်` |
| `ကြောင့်` | ⚠ 原因；对应与格 / 具格表"为了 / 由于"（`kiriyāya`、`pavattiyā`），具格表原因时也用（`iminā` → `ကြောင့်`） | `kiriyāya ကြောင့်` |
| `ငှါ` | 不定式 -tuṃ（目的），也对应与格 | `paññapetuṃ ငှါ` |
| `အား` | 与格（给予、对……） | `nesaṃ … ထိုနိဂဏ္ဌတို့အား`、`aññesaṃ … တို့အား` |
| `တို့၏` / `တို့အား` / `တို့ကို` | 复数 + 属格 / 与格 / 宾格 | `nigaṇṭhānaṃ တို့၏` |
| `မှ` | 从格（起点） | `ပြီးသည်မှ နောက်` |
| `အားဖြင့်` | 具格（凭借、就……而言） | `အနက်အားဖြင့်`（就意义而言） |
| `တွင်` | 属格 / 处格表"在……之中"（取舍） | `imesaṃ tiṇṇaṃ daṇḍānaṃ … တွင်` |
| `သော` | 定语：前一词修饰后一词 | `mahatiyā များပြားသော` |
| `ကုန်သော` | 复数定语 | `tīṇi … သုံးပါးကုန်သော` |
| `တို့` | 复数 | `āsanāni နေရာတို့သည်` |
| `မည်သော` | "名叫……的"（专名） | `dīghatapassī ဒီဃတပဿီမည်သော` |

### 动词与句式

| 语尾 | 对应巴利 | 例 |
|---|---|---|
| `၏`（句末） | 现在时陈述 | `viharati ၏`、`paṭivasati နေ၏` |
| `ကုန်သည်` | 复数现在时 | `saṃvijjanti ရှိကုန်သည်` |
| `ပြီ` | 过去（aorist） | `aṭṭhāsi ပြီ`、`nisīdi ပြီ` |
| `၍` | 连续体 -tvā | `gahetvā ယူ၍` |
| `အပ်၏` | 义务分词 -tabba（"应当……"） | `dātabbaṃ ပေးအပ်၏` |
| `စေ` | 使役（-āpeti / -eti 的使役义） | `samādapeti ဆောက်တည်စေ၏` |
| `မ…` | 否定 na | `na dātabbaṃ မပေးအပ်` |
| `ပါ၏` / `ပါကုန်အံ့` | 敬语：说话人对上位者（居士对佛） | `abhiraddho … နှစ်လိုကြည်ညိုပါ၏` |
| `သော်` | 独立处格（"……时 / ……之后"） | `evaṃ vutte သော်` |
| `အံ့` | ⚠ 将来 / 祈愿；配 `sace` 表条件 | `sace ākaṅkhasi … လိုသည်ဖြစ်အံ့`、`jānissāma သိကြပါကုန်အံ့` |
| `လော့` | 命令 | `nisīda ထိုင်လော့` |
| `သနည်း` | 带疑问词的问句 | `kati … paññapeti ပညတ်ထားသနည်း` |
| `လော` | 是非问句 | `aññadeva … ဖြစ်သလော` |
| `တည်း` | 判断（无动词的名词句） | `aññaṃ တည်း` |
| `ဟူ၍` / `ဟူသော` | iti：引语结束；`ဟူသော etaṃ` 表"……这话" | `kammaṃ kammanti ကံ ကံ ဟူ၍` |
| `သာ` / `သာလျှင်` | 强调小品词 kho / eva | `aññadeva အခြားတပါးသာလျှင်` |
| `၎င်း` | 列举（"……和"），对应 ca 或并列 | `kāyadaṇḍaṃ ၎င်း` |

## `iti` 的讲法交代谁对谁说

`iti` 的 gloss 带说话动词，动词的敬语等级显示说话人与听话人的关系：

| gloss | 意思 |
|---|---|
| `ဤသို့လျှောက်၏` | 下对上说（弟子、居士、外道对佛） |
| `ဤသို့မေးတော်မူ၏` / `မိန့်တော်မူပြီ` | 佛问 / 佛说（`တော်မူ` 是对佛的尊敬语） |
| `ဤသို့ပြော၏` | ⚠ 不带敬语的"说"：平辈之间，或转述他人时（`ဤသို့ပြောဆိုသည်` 用于转述「沙门乔达摩这样说」） |

引语层层嵌套、主语省略时，靠它判断**这句话是谁说的**——评审「指代错误」「主谓判断」时很有用。

## 补出的巴利（不是原文内容）

nissaya 会补出原文省略、而讲解需要的词：

- `bhagavā etadavoca` 拆开讲成 `… ဟူသော etaṃ ကို avoca ပြီ`——`etaṃ … avoca` 是为了
  串起引语而补的；
- `seyyathidaṃ` 讲成 `seyyāthā katamāni … idaṃ-imāni`——把单数 `idaṃ` 换成该用的
  复数 `imāni`，再补出 `paññapeti`；
- 引语前补主语、补被省略的动词。

**gloss 里圆括号内的缅文**也是补出的，是为了读通而加的成分，常常补出**人称**或**来源**：
`vadāmi (ကျွန်ုပ်) ဆို၏`（"（我）说"）、`sutaṃ (နိဂဏ္ဌတို့ထံမှ) ကြားဘူးပါ၏`（"（从尼乾陀们那里）
听说过"）。它们是 nissaya 的理解，不是原文；但用来核对译文的人称、指代很直接。

评审时：**译文没译这些补出的词不算「漏译」**——补词怎么定级见 `translation-evaluate.md`
「用 nissaya 审稿」。

## 省略记号

- `ပ`：「以下略」。**跳过的范围不固定**：可能是句内几个词，也可能是后面整句甚至几句。
  - 句内：`imināpi ကြောင့်လည်း။ပ။ abhiraddho …`——跳过了 `bhagavato bhiyyosomattāya attamano`，
    其中有实词；
  - 跨句：`jānissāma … ။ပ။` 之后，下一句 `Esāhaṃ, bhante, tatiyampi … saraṇaṃ gacchāmi …`
    整句没有条目（皈依套语前文已讲过）。

  被跳过的词**没有讲解**，不要当成 nissaya 认为这些词可以不译。
- **只写前文同一 gloss 的末音节**，即"同上"，不是新的意思。这一章最常见的几个：

  | 缩写 | 全写 | 对应 |
  |---|---|---|
  | `ဿီ` | ဒီဃတပဿီ | tapassi |
  | `မ` | ငါ့ရှင်ဂေါတမ | āvuso gotama |
  | `ကြွယ်` | သူကြွယ် | gahapati |
  | `ရား` | အရှင်ဘုရား | bhante |
  | `အပ်` | မပေးအပ် | na dātabbaṃ（重复时） |
- `ပေးမြဲ`（"照例"）：套语 `evaṃ me sutaṃ` 不再逐词讲。
- 方括号 `[ … ၅၆-ဝါကျကို မှီး၍ ပေးလေ]`：「仿照第 56 段讲」，括号里只列出与那段不同的词
  （如"只有『杖』与『业』不同"）。要回到那一段去读。

## 释义不是译名

有些 gloss 是**解释**，不是对译：

- `nāṭaputto ကခြေသည်၏သားဖြစ်သော`（"舞者之子"）——是对名字的词源解释；
- `paṭivibhattānaṃ အနက်အားဖြင့် ကွဲပြားကုန်သော`（"就意义而言有区别的"）；
- `atha ca pana ထိုသို့ကြားဘူးသော်လည်း`（"虽然听说过那样"）——把连接词讲成了它在上下文
  里的语义。

**不要拿释义去要求译文照搬**，也不要因为译文用了通行译名（若提子）而判「词义误译」。
释义能帮助判断译文对词义的理解是否到位。

## 夹注：分清层次

- **引注释书**，引用时按层次标明（`conventions.md`「文献层次必须标明」）：
  - 以 `ဋီ` / `(ဋီကာ)` 结尾的是复注（ṭīkā）：`(ပဋိဝိဘတ္တာနန္တိ အတ္တတော ဘိန္နာနံ။ ဋီ)`；
  - 以 `ဋ္ဌ` / `(အဋ္ဌကထာ)` 结尾的是义注（aṭṭhakathā）；
  - 同一条 gloss 里可能并列两层：`… (အဋ္ဌကထာ)။ … (ဋီကာ)။`，分别对待；
  - 还会引**别的经**的注释：`စူဠသစ္စကသုတ် ဋီကာ`（《萨遮迦小经》复注）。
- **脚注**：用 ` `` ` 包起、带编号（`၁။ …`）的块，内容多是上面这类引文。
- 不带出处的括号是**编者按语**，如"此处 iti 似为衍字，他本 seyyathidaṃ 前无 iti"。
  这是编者意见，可作参考，不是任何一层原典。

## nissaya 里的巴利拼写不可靠

nissaya 引的巴利词常有录入错误：`saddiṃ`（saddhiṃ）、`cariyā`（caritvā）、
`kabhamaṃ`（katamaṃ）、`daṇṭhāni`（daṇḍāni）、`bhagatā`（bhagavā）、`ဂပဟတိ`（gahapati）、
`မဟာသာဝဇ္ဇတ၇ံ`（把字母 ရ 打成了数字 ၇）、`နမဟပ္မလံ`（na mahapphalaṃ）。**这些不是异读**，
异读以原文 channel 的方括号注为准。

## 权威排序

**巴利原文 > 注释书（义注、复注） > nissaya > 其他译文。**

- nissaya 代表缅甸传统的语法理解，是**有力佐证**：译文的主谓宾、修饰、指代与它不一致时，
  要回到原文认真复核。
- 与注释书冲突时以注释书为准。
- **用 nissaya 发现，用巴利原文确认**：定 `error` 要能从巴利语法或注释书说明为什么错。正文里写清
  nissaya 怎么讲、原文语法依据是什么。
