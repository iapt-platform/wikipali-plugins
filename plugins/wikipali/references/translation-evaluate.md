# 译文评价标准

校对、审稿、评估译文时按本标准给问题分类、定级。**本文件对本插件的所有 skill 一律有效**，
与 `conventions.md` 同级。

问题分三级，正好对应 issue 批注的 `--severity`：

| 级别 | `--severity` | 谁会发现 | 处理 |
|---|---|---|---|
| 错误 | `error` | 普通读者（严重错误）/ 巴利专家（一般错误） | 只要发现，一定要改 |
| 待提升 | `warning` | 出版社编辑 | 应当改 |
| 可提升 | `suggestion` | 有佛教背景的读者 | 建议改 |

## 错误 `error`

### 严重错误（零容忍）

会增长普通读者的邪见、降低普通读者对译文的评价。仍标 `error`，标题里的类别就写
「严重失真」「教理违背」，排在其它问题之前报告。

1. **严重失真**：主语、谓语（含非谓语动词）、宾语有一项判断错误，导致句意严重失真
2. **教理违背**：句意违背基本教理原则

### 一般错误（专家有举必究）

只有巴利专家能发现，但只要发现就一定要改。

1. **漏译**：原文中有的内容在译文中缺失
2. **多译**：译文中增加了原文没有的内容
3. **词义误译**：词语的意思翻译错误
4. **修饰错误**：修饰关系判断错误
5. **误解表达**：表达方式会导致读者误解
6. **义理不符**：义理与注释书不符
7. **用词不符**：用词与注释书不符——含 `conventions.md`「被解释词必须与所注文本用词一致」：
   义注黑体的被解释词与根本同处译法不一致、复注与义注不一致，都归这一类
8. **指代错误**：代词指代的对象错误

## 待提升 `warning`

1. **语意不明**：关键词语意不明确
2. **缺少注释**：二意场合没有添加注释
3. **指代不明**：代词指代不够明确，可能影响理解
4. **汉语语病**：不导致误解的汉语语病
5. **标点错误**：标点符号使用错误
6. **误用标记**：不该使用术语标记时使用了术语标记
7. **逻辑不规范**：整句逻辑表达不规范

## 可提升 `suggestion`

1. **表达晦涩**：语言表达不够流畅
2. **代词指代**：代词指代可以更明确（不影响理解；影响理解的归 warning「指代不明」）
3. **风格统一**：语言风格不统一——含 `conventions.md` 的风格要求：前后一段现代汉语、
   一段半文半白，归这一类
4. **术语标记**：该使用而没有使用术语标记
5. **缺少注释**：不常用术语需要编写注释或百科
6. **句式复杂**：嵌套句太复杂，整句逻辑难以理解，对读者不友好

## 怎么用

- **判断依据是巴利原文**，义理、用词以注释书为准（`wikipali related` 找义注复注）。
  没读原文和注释就不要定 `error`。
- 有缅文 **nissaya** 时要用它审稿，怎么定级见下一节「用 nissaya 审稿」；读法见同目录的
  `nissaya-reading.md`。
- **一个问题一条 issue**，格式固定，见下一节「issue 的格式」。
- 能定位到具体文字就给 `--quote-exact`（摘自**译文**），阅读页才高亮得出。
- 拿不准该归哪一级时，按更重的一级标，并在正文里说明理由。
- `suggestion` 里的「术语标记」只在该 channel **本来就用**术语标记时才提——本插件翻译默认
  不加（`conventions.md`），不要据此给默认风格的译文挑错。「缺少注释」同理，**例外是
  nissaya 里的解释性内容**：可以照下一节建议加脚注。
- 汇总报告时按 `error` → `warning` → `suggestion` 排序，`error` 里严重错误在前。

## issue 的格式

**标题**：`[类别] 简要描述`。类别取本文各级下的条目名，原样照写；描述一句话说清错在哪。

```
[漏译] tajjanīya 未译出
[语意不明] āciṇṇa 译作「不习惯」
[严重失真] 主语判断错误：施事者误作世尊
```

**正文**：固定四项，按顺序，一项都不能少：

```markdown
1. **原文**：*Na kho, āvuso gotama, āciṇṇaṃ nigaṇṭhassa nāṭaputtassa*
2. **译文**：「并不习惯施设」
3. **理由**：āciṇṇa 是"惯例、惯常的做法"。nissaya：*na kho āciṇṇaṃ အလေ့အကျက်မဟုတ်သော*
   （"不是惯常的做法"）。现代汉语"不习惯"常指"不适应"，会读成若提子对这个说法不适应。
4. **建议修改为**：「尼乾陀·若提子的惯例不是施设'业、业'」
```

- **正文里不用反引号**（`` `文字` ``）：巴利、缅文、引文一律用斜体 `*文字*` 标出。
  建议的脚注也照此写，不要写成译文里那种反引号注释语法。
- **原文**：只摘出错的那一段巴利，不抄整句；漏译就摘被漏掉的词。用斜体，照原文拼写。
- **译文**：只摘出错的那一段，与 `--quote-exact` 一致；漏译写出漏在哪个位置附近的译文。
- **理由**：写依据——巴利语法、nissaya 怎么讲（缅文原样附上，括注汉语意思）、注释书
  怎么说（标明义注 / 复注及坐标）。几条依据可以分行。
- **建议修改为**：给出可以直接替换的译文。有多种改法时都列出；只建议加脚注时写出脚注全文；
  `suggestion` 若只是建议考虑、不必改，也要写明「可保留原译，或改为……」。

## 用 nissaya 审稿

缅文 nissaya 的语尾、补词、释义是逐词的语法分析，拿它和译文逐词对照，能找出只有
巴利专家才看得出的错误。先读 `nissaya-reading.md`，再按下表定级：

| 对照结果 | 级别 | 归类 |
|---|---|---|
| 译文的词义、用法与 nissaya 的讲法不符：格位、时态、主被动、修饰关系、代词指代 | `error` | 词义误译 / 修饰错误 / 指代错误；主谓宾判断错误致句意失真的是**严重**失真 |
| 译文有明显歧义（可以读成两种意思），nissaya 的讲法明确 | `warning` | 语意不明 / 指代不明 |
| nissaya 补了词、指明了代词指的是谁，原文没有，译文也没写 | `suggestion` | 代词指代 / 表达晦涩；建议照 nissaya 补出 |
| nissaya 里的解释性内容（释义、引义注复注）能帮读者理解 | `suggestion` | 缺少注释；建议加脚注 |
| nissaya 有、巴利原文没有的内容，译文没有 | `suggestion` | 不是漏译；需要时建议补 |
| 巴利原文有、译文没有 | `error` | 漏译——**以巴利原文为准**，nissaya 用 `ပ` 跳过、或整句没有条目的地方照样要查 |
| 译文有、巴利原文没有 | `error` 多译；若与 nissaya 的补词一致、且汉语确实需要，不算错 | 多译 |

要点：

- **用 nissaya 发现，用巴利原文确认。** 定 `error` 时，正文里写明 nissaya 怎么讲（语尾、
  释义）、原文的语法依据是什么。nissaya 与注释书冲突时以注释书为准；nissaya 本身的
  巴利拼写错误（见 `nissaya-reading.md`）不是依据。
- **建议加脚注时，脚注内容要标来源**：取自 nissaya 的写「**Nissaya**：」，nissaya 引的是
  义注、复注的，按原层次写「**义注**：」/「**复注**：」（`conventions.md`「文献层次必须标明」）。
- nissaya 里的释义**不是译名**：译文用了通行译名、意思没错，不因为与释义字面不同而定错。
