# 解析引用缩写

缅甸佛教著作的脚注习惯写成 `<书的缩写>၊<册>၊<页>`，例如 `ဝိသုဒ္ဓိ၊၂၊၂၄၁`。
本 skill 把这种缩写解析成**是哪一部著作、对应 WikiPali 的哪一本书**。

一条命令，**离线**，不发请求也不需要登录：

```bash
wikipali cite 'ဝိသုဒ္ဓိ၊၂၊၂၄၁'
wikipali cite 'မဟာဋီ-၂-၄၀၁' 'ပြည်-ဝိသုဒ္ဓိမဂ်နိဿယ-၃-၂၄၁' 'vism-2-241'
```

⚠ **刚装好或刚更新插件时 `wikipali` 可能还不在 PATH 上**——PATH 注入在会话启动时完成。
若 `command -v wikipali` 为空，改用 `${CLAUDE_PLUGIN_ROOT}/bin/wikipali`，并提醒用户重启会话。

## 铁律

1. **引用里的数字是缅甸版的页码，不是 WikiPali 的段落号。** 两者**毫无关系**——
   清净道论第 2 册第 241 页不是 `65:241`。**绝不许**把页码直接写成坐标交给用户，
   那会把人带到完全不相干的段落上。本 skill 只回答「是哪本书」。
2. **表里没有的缩写就说没有。** 缅文缩写彼此形近（`မ`＝中部、`မဟာဋီ`＝大复注、
   `မူလဋီ`＝根本复注），猜错一个字就是另一部书。`wikipali cite` 报「表里没有这个缩写」
   时，如实说不认识，让用户给出上下文（前后文里常有全名），不要挑一个像的顶上。
3. **缅文著作在 WikiPali 里没有对应。** 尼思耶（`နိဿယ`）、缅文复注（`ဘာသာဋီကာ`）、
   缅文纲要书（`ကျမ်း`）都是缅文写的，WikiPali 收的是巴利文献。这类引用只能报出
   **底本**是哪部巴利著作，**册页不能换算**——尼思耶的分册与巴利本的分册不是一回事。
4. **缅甸版的册 ≠ WikiPali 的书。** 相应部缅甸版 3 册，WikiPali 按 5 品分成 5 本；
   增支部缅甸版 3 册，WikiPali 按 11 集分成 11 本。所以「第 2 册」定不了书，
   **要靠页码**落在哪本书的缅甸版页码区间里。这一步 `wikipali cite` 已经做了。

## 怎么读命令的输出

```
ဝိသုဒ္ဓိ၊၂၊၂၄၁
  缩写   : ဝိသုဒ္ဓိ   第 2 册  缅甸版第 241 页
  著作   : Visuddhimagga　清净道论　（aṭṭhakathā）
  → 书名 : Visuddhimaggo(Dutiyo bhāgo)　（缅甸版 M2.1–353，起于 65:2）
  → 坐标 : 65-<段落号>　（段落号未解析：引用给的是页码，不是段落）
```

给用户的回答照这个说：**著作名（巴利＋中文）、文献层次、WikiPali 的书名与 book id、
册与页**。坐标写成 `65-<段落号>` 的形状，并**明说段落号还没解析**。

定不到具体哪一部时命令会列出候选并说明原因（`book:起始段  书名  M册.首页-末页`），
照实转述，**不要从候选里随便挑一个**。

## 命令解析不了时，手工按这个来

数据在插件自带的两张表里，**不要联网取**：

| 文件 | 内容 |
|---|---|
| `references/citation-abbrev.tsv` | 缩写（缅文写法 \| 罗马化别名）→ 著作、中文名、候选 book id、册号对照 `vol_map`、文献层次、备注 |
| `references/citation-books.tsv` | WikiPali 收的**每一部著作**一行：`book`、该部起始段 `para`、**toc 书名**（书名取 `toc` 字段，不是 `title`）、tags、缅甸版册 `m_vol` 与页码区间 `m_first`–`m_last`、各版（V=VRI / P=PTS / T=泰版）区间 |

拆解步骤：

1. **缅文数字转阿拉伯数字**：`၀၁၂၃၄၅၆၇၈၉` = `0123456789`。
2. **按分隔符切开**：`၊`（缅文逗号）、`။`、`-`、`、`、`,`、`.`、空格都用过，同一份文献里
   甚至混着用（`ဝိသုဒ္ဓိ၊၂၊၂၅၁` 与 `ဝိသုဒ္ဓိ-၂-၂၄၁` 是同一种写法）。
3. **非数字的部分拼回书名**，用 `-` 连接：`အဘိ၊ဋ္ဌ၊၂၊၂၅၂` 的书名是 `အဘိ-ဋ္ဌ`（论藏义注），
   `ဋ္ဌ` 是 `အဋ္ဌကထာ`（义注）的缩写，`ဋီ` 是 `ဋီကာ`（复注）的缩写。
4. **数字部分**：最后一个是页码，前一个（若有）是册号；`သံ၊၂၊၂၄၉-၂၅၀` 这种是页码范围。
   只有一个数字就是没有分册的书（如 `ပဋိသံ၊၅၂` 无碍解道第 52 页）。
5. **版本前缀**要认出来：`ပြည်` 是「卑谬版」，属于版本而非书名的一部分。
6. 拿书名去 `citation-abbrev.tsv` 查 `abbrev_my`（多种写法用 `|` 分隔）或 `aliases`
   （罗马化，去变音符后小写比对），得到候选 book id。
7. 在 `citation-books.tsv` 里定位：
   - 先按册。多数书组的页码标记自带册号（`m_vol`），比对册号即可；
     但缅甸版论藏义注三册都标成 `M0.x`，册号不在标记里——这类在
     `citation-abbrev.tsv` 的 `vol_map` 列里人工写死了（`1=96;2=97;3=98`）。
   - 再按页。**页码在一册之内跨著作连续编下去**（实测 `100:3` 是 M2.1–67、
     `100:325` 接 M2.69、`100:997` 接 M2.249），所以「起始页不大于该页的
     最后一部」就是答案，不必依赖 `m_last`。

**候选的单位是著作，不是书。** 一个 book 里可能收好几部各自独立编页的著作——
book 98 收了五论义注中的五部，book 174 收了根本复注的五部。所以表里一部一行，
`para` 是该部在书内的起始段。

## 页码 → 段落号（还没做的那一步）

WikiPali 的正文里夹着各版页码标记 `<code>M2.241</code>`——**M=缅甸版、V=VRI、
P=PTS、T=泰版**，标的是该页在正文中的起始位置。所以页码是能换算成段落号的：
在该书的叶子章节里找 `M<册>.<页>`，它所在的 `data-para` 就是段落号。

但这要逐章取正文（`GET /v2/tipitaka-content/{book}-{para}`），一本书上百个叶子章节，
**目前插件没有这份索引**。所以现在只答到书为止。用户若追问具体段落，如实说明这一步
需要按章检索，并可以用 `wikipali paras <book>:<起始段>` 先看章节结构。

## 数据的已知毛病

- **页码区间是抽样得来的**（每部著作只扫首尾若干章），接缝上的页可能落在两部之间。
  命令遇到这种情况会说「可能落在分册接缝上」，转述时别把它说成确定结果。
- **有些著作没有页码标记**（`m_first` 为空），这类只能报到「候选是这几部」为止。
  同一册里只要还有这样的著作，命令就不会硬断到别的一部上——它宁可报不确定。
- **`m_last_derived` 为 1 的行**，上界是拿下一部的起始页推出来的，不是扫出来的。
- **`vols_seen` 是原始引用里出现过的册号，含手误**——增支部出现过「第 18 册」，
  缅甸版增支部只有 3 册，那是原书的排印错误。
- **不分册的书，页码标记记作 `M0.x`**（如无碍解道 M0.1–418），不是「第 0 册」。
- 表来自一份具体的缅文著作的引文统计（173 条引用、75 部著作），**不是缅甸引用缩写的
  全集**。冷僻缩写查不到很正常。
